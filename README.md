# SecureCart Cybersecurity Risk Management Project

## 1. Project Overview

SecureCart is an Australian e-commerce project used for the ITSU2006R IT Project Management Assessment 3.

The project focuses on identifying cybersecurity risks, assessing their potential impact, and developing a practical risk management and treatment plan to improve the security, reliability, and protection of customer information.

This repository contains the project management documents, cybersecurity risk analysis, project schedule, risk register, and supporting evidence prepared for the assessment.

## 2. Project Objectives

The main objectives are to:

- Identify important assets, systems, and information within the SecureCart project.
- Analyse potential cybersecurity threats and vulnerabilities.
- Assess cybersecurity risks using likelihood and impact.
- Develop a risk register and risk treatment roadmap.
- Prepare project planning, communication, quality, and change management documents.
- Review the project deliverables and prepare the final report.
